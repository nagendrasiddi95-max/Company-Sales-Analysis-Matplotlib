# Company Sales Analysis Using Python

## Project Overview
This project analyses a sample company's sales and profit data using Python and Matplotlib. It uses five visualisations to understand business performance.

## Tools Used
- Python
- Matplotlib

## Project Objectives
- Analyse monthly sales.
- Compare monthly profits.
- Identify the top-performing sales category.
- Understand sales distribution.
- Analyse the relationship between sales and profit.

## Visualisations
1. Line Chart – Monthly Sales Analysis
2. Bar Chart – Monthly Profit Analysis
3. Pie Chart – Category-wise Sales
4. Histogram – Sales Distribution
5. Scatter Plot – Sales vs Profit

## Key Business Insights
- June recorded the highest sales of ₹25,000.
- June recorded the highest profit of ₹6,000.
- Electronics contributed 40% of total category sales.
- Sales and profit show a positive relationship in this sample.

## Dataset
A sample dataset containing six months of sales and profit figures and four product categories.

## How to Run
1. Install Python.
2. Install Matplotlib using `pip install matplotlib`.
3. Run `python sales_analysis.py`.

## Conclusion
This project demonstrates basic Python data visualisation skills and the use of charts to communicate business insights.
